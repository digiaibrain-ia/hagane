# Contribuindo

- **Branches:** `main` (estável), `feat/<assunto>`, `fix/<assunto>`, `docs/<assunto>`.
- **Commits:** português, imperativo curto. Prefixos: `feat:`, `fix:`, `docs:`, `plc:`, `nodered:`, `dashboard:`.
- **Tags:** `dashboard-vX.Y.Z`, `plc-vX.Y`, `nodered-vX.Y`.
- **Versões:** arquivos versionados no nome (`nome_v0.1.html`); versão antiga vai para `arquivo/`.
